# Neon Beetle Assault

Небольшой браузерный аркадный шутер на Canvas и ванильном JavaScript.

## Запуск локально

Проект использует ES-модули, поэтому откройте его через HTTP-сервер:

```bash
python -m http.server 8000
```

Затем перейдите на <http://localhost:8000>.

## Управление

- Стрелки или A/D — движение
- Space — стрельба
- E — бомба
- P — пауза

## Публикация

GitHub Actions публикует статические файлы проекта в GitHub Pages после отправки коммита в `main`.
